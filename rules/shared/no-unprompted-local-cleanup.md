# 禁止无端清理本机已有的东西

除当次任务亲手创建的临时产物外，本机已有的任何目录、文件、备份、命令、脚本、配置、常驻任务和容器，未经用户本人逐项明确确认，一律不得删除、移入废纸篓、覆盖、清空或停用。看起来陈旧、无人引用或没有纳管，都不能作为理由。

- **发现疑似冗余：** 只记录对象的路径或名称、现状和判断依据，在回复中请示用户；在用户逐项确认之前保持原样，也不自行判定它是废物。
- **当次自建的临时产物：** 本次任务亲手创建的临时文件、临时目录、一次性容器，可以按其他规则正常清理。
- **不属于清理：** 当次任务所要求的改动本身不受本规则限制，包括在仓库内通过 git 提交的代码和文档修改与删除，以及用户为该任务明确点名的删除或停用。
