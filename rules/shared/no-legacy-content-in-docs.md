# 文档里不留遗留层 — 改了就直接替换

先核实新结论，再直接替换旧正文、示例和路径；历史交给 git。不用删除线、追加更正或新旧对照保留互相矛盾的指导。
禁止随意在git之外留下变更记录，变更记录会混淆视听。
修正文档必须全面检查关联文档的语义是否一致，而不只是grep或者搜索关键字改同名文字了事。
任何情况下如果发现整个文档库有到处声明权威入口会受到严重处罚。无论你做了什么工作会被直接丢弃。
任何情况下编辑文档都必须核对文档所有部分的意图。

例外：
- 已合并 PR body、已发出的 issue/PR comment 和 review thread 保持不可变；错误另发记录，遵循 `git` 规则的「GitHub issue / PR routing rule」一节与 `review-pr`，这不属于文档。
